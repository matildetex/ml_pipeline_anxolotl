1. ALGORITHM PARAMETERS (detect_markers, 3_anxolotl/anxolotl_preprocessing.py:132)
------------------------------------------------------------------------------
Signature defaults actually used in production (preprocess_session never
overrides bridge_gap_sec or relax_level_frac -- see call site at line 652):

  z_percentile          = 85     (adaptive threshold: 85th pctile of the
                                   session's OWN 1s-median z-axis distribution)
  min_duration_sec      = 8      (arm must stay above threshold >= 8s)
  min_gap_sec           = 120    (min spacing between markers 2..8)
  baseline_duration_sec = 300    (min spacing enforced between marker 1 and 2)
  bridge_gap_sec        = 0      (ACTUAL default; docstring says 3 -- MISMATCH,
                                   no gap-bridging happens in production runs)
  relax_level_frac      = 0.45   (ACTUAL default; docstring says 0.6 -- MISMATCH)
  min_gesture_amplitude = 0.15   (min resting->raised z amplitude to attempt relaxed pass)
  relax_min_duration_sec= 5      (min duration for a relaxed-pass candidate)
  relax_max_std_frac    = 0.35   (max variance, as frac of amplitude, for a
                                   relaxed candidate to be accepted as a plateau)

DOCSTRING/CODE MISMATCH FLAGGED: the docstring for bridge_gap_sec and
relax_level_frac states different default values than the function signature
actually uses. Since preprocess_session() calls detect_markers() without
overriding either, the REAL behaviour in every one of the 37 processed
sessions is bridge_gap_sec=0 (no dropout-bridging at all) and
relax_level_frac=0.45, not the values the docstring describes.

Core detection logic:
  1. z_1s = 1-second median of raw ACC z-axis (robust to single-sample noise)
  2. z_threshold = percentile(z_1s, 85)  -- adaptive per session, no fixed volts
  3. raised = z_1s > z_threshold; find contiguous True-runs >= 8s long
  4. Greedy protocol-aware selection: marker1->2 gap >= 300s, all others >= 120s
  5. Relaxed second pass on the unexplored tail if < 8 markers found, using a
     per-subject-calibrated threshold (45% of the subject's own resting->raised
     amplitude), only if that subject's confirmed gestures show amplitude >= 0.15
  6. Structural sanity check: inter-marker spacing must be 100-400s or the whole
     session is rejected as having no valid gestures
  7. Minimum 4 markers required to accept a session at all (else ValueError)
