3. MARKER-PROXIMITY CONFOUND TEST
------------------------------------------------------------------------------
Re-running detect_markers() on raw sessions (same defaults preprocess_session() uses: n_markers=8, z_percentile=85, min_duration_sec=8, marker_min_gap_sec=120, baseline_duration_sec=300).

  Markers recovered for 37/37 subjects (failed/missing: none)

  Alignment check OK: meta rows match df_feat rows 1:1 (acc_wrist_min, subject, label).

  Windows with a marker time available: 686/686

  Spearman(acc_wrist_min, distance from window's own arg-min to nearest marker) = -0.3078  (p=1.597e-16)
  Positive rho would mean "closer to marker => lower min" (supports gesture-aftermath
  contamination). The measured rho is NEGATIVE and highly significant: closer to a marker
  associates with a HIGHER acc_wrist_min, and windows far from any marker have LOWER minimums.
  This is the OPPOSITE of the contamination hypothesis -- it is not consistent with "the
  quiet/apnea moment right after a gesture is what's producing low mins nearby." If anything,
  the gesture itself (arm raise + breathing, ~8-15s of elevated motion) keeps nearby windows'
  minimums elevated, and the lowest mins occur in stretches well away from any protocol event.

  [BASELINE] extreme acc_wrist_min windows (bottom/top 10%, n=69): median dist-to-marker=127.2s
  [BASELINE] typical windows (middle 80%, n=265): median dist-to-marker=135.1s
  [BASELINE] Mann-Whitney U=8396.0, p=2.964e-01

  [STRESS] extreme acc_wrist_min windows (bottom/top 10%, n=72): median dist-to-marker=77.5s
  [STRESS] typical windows (middle 80%, n=280): median dist-to-marker=55.4s
  [STRESS] Mann-Whitney U=13049.0, p=1.158e-04

  [BASELINE only] Spearman(acc_wrist_min, dist-to-marker) = -0.1400  (p=1.041e-02, n=334)
  [STRESS only] Spearman(acc_wrist_min, dist-to-marker) = -0.1730  (p=1.116e-03, n=352)

  CONCLUSION 3: marker-proximity confound is REJECTED by this test, in the specific form
  hypothesised (gesture aftermath -> artificially LOW min nearby). The correlation between
  acc_wrist_min and distance-to-marker is real, significant, and survives stratifying by
  class (baseline: rho=-0.140, p=0.010; stress: rho=-0.173, p=0.001), but it runs the
  opposite direction: windows near a marker have HIGHER minimums, windows far from any
  marker have LOWER minimums. The STRESS-only extreme-vs-typical test (p=1.16e-04) is
  significant in the same direction (extreme-value stress windows sit ~78s from a marker vs
  ~55s for typical stress windows -- i.e. extremes are farther away, not closer). So the low
  acc_wrist_min values that dominate the SHAP signal are not a marker-detection artifact;
  they occur during genuine mid-phase stretches away from the protocol's gesture events.
